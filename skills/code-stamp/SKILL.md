# Code Stamp

Use the bundled Code Stamp web interface when the user asks to generate a QR code or barcode.

The interface is in the plugin root at `dist/index.html`. For local development or changes, run `npm install`, then `npm run build` and `npm run dev` from the plugin root. The page supports QR codes, Code 128 barcodes, custom foreground and background colors, optional center icons, preview, and PNG download.
